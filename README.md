🤖 ROBOT CONTROL SYSTEM

1. Présentation du projet

ROBOT CONTROL SYSTEM est une application développée en Python avec Tkinter. Elle permet de simuler et de contrôler un robot mobile dans un environnement contenant des obstacles.

Le système propose un contrôle manuel et un mode automatique permettant au robot de se déplacer tout en détectant et en évitant les obstacles.

2. Objectifs du projet

* Simuler le déplacement d’un robot mobile.
* Permettre le contrôle manuel du robot.
* Détecter les obstacles à l’aide d’un capteur.
* Éviter les collisions.
* Automatiser le déplacement du robot vers une destination.
* Proposer une interface graphique simple et interactive.

3. Fonctionnalités principales

* Contrôle manuel : déplacement et orientation du robot.
* Mode automatique : déplacement automatique vers une destination.
* Détection des obstacles : utilisation d’un capteur pour repérer les obstacles.
* Évitement des obstacles : adaptation du déplacement pour éviter les collisions.
* Simulation : visualisation du robot et de son environnement.
* Configuration : possibilité de définir les positions du robot, des obstacles et de la destination.

4. Technologies utilisées

* Python 3
* Tkinter
* Programmation orientée objet (POO)
* Git et GitHub

6. Installation et exécution

Prérequis

* Python 3 installé sur l’ordinateur.
* Tkinter disponible.

Récupération du projet

git clone https://github.com/boussobaly098/ROBOT_CONTROL_SYSTEM.git

Accéder au dossier

cd ROBOT_CONTROL_SYSTEM

Lancer l’application

python3 main.py

7. Tests

Le projet contient plusieurs fichiers de tests permettant de vérifier le fonctionnement des différentes parties du système.

Pour lancer les tests :

python3 -m unittest discover -p "test_*.py"

8. Conclusion

Ce projet nous a permis de mettre en pratique les notions de programmation Python, de programmation orientée objet, de simulation et de développement d’interfaces graphiques.

Il constitue une première approche de la robotique mobile, du contrôle automatique et de l’évitement des obstacles.
